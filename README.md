# boAt Lifestyle - Official Web Storefront

A responsive e-commerce web application inspired by **boAt Lifestyle**.

## 🛠️ Complete Feature Matrix
1. **Search & Multi-Filtering:**
   - Real-time product search with dropdown auto-suggestions.
   - Category filtering pills (Earbuds, Smartwatches, Neckbands, Soundbars, Speakers, ANC).
   - Price range slider up to ₹6,000.
   - Sort dropdown (Popularity, Price: Low to High, Price: High to Low, Rating).
2. **Product Image Slider / Carousel:**
   - Multi-image gallery with Next (`>`) and Prev (`<`) buttons.
   - Interactive thumbnail switching.
3. **Cart & Wishlist (Frontend Only):**
   - Slide-over cart and wishlist drawers with item count badges.
   - Quantity decrement/increment (`+` / `-`).
   - Coupon promo code system (`BOAT15` for 15% discount).
   - "Move to Bag" from Wishlist.
4. **Dark / Light Mode:**
   - Single-click theme toggle stored in `localStorage`.
5. **Loading Skeletons & Spinner:**
   - Smooth skeleton cards on products load.
   - Global boAt Nirvana spinner on page transitions.
6. **Authentication & Form Validation:**
   - Login and Sign Up with regex email check and password match validation.
7. **Mobile, Tablet & Desktop Responsive:**
   - Responsive navbar with mobile drawer menu.

## 🚀 How to Run

1. Extract `boat-lifestyle.zip`:
   ```bash
   unzip boat-lifestyle.zip
   cd boat-lifestyle
   ```
2. Install dependencies:
   ```bash
   npm install
   ```
3. Run the development server:
   ```bash
   npm run dev
   ```
4. Open the browser at `http://localhost:5173`.
